🐍 Nokia Snake Game Project

This project is a classic Nokia Snake Game recreated using Python.
The player controls a snake that moves around the screen, eats food, grows longer, and avoids collisions with walls and itself.

This project is perfect for beginners to understand basic game development concepts such as loops, events, conditions, and graphics handling.

📘 Project Overview

The Snake Game is one of the most iconic mobile games originally popularized by Nokia phones.
In this project, the game is implemented using Python and Pygame, allowing users to experience the classic gameplay on a computer.

The snake grows longer each time it eats food, making the game progressively more challenging.

🎯 Objective

To recreate the classic Nokia Snake Game using Python

To understand basic game mechanics such as movement, collision detection, and scoring

To learn how to use the Pygame library for 2D game development

To build logic using loops, conditions, and keyboard events

🧠 Game Concept

The snake moves using arrow keys

Food appears at random positions

Each time the snake eats food, its length increases

Game ends if:

Snake hits the wall

Snake collides with itself
